# Level 17 — Traits

## What you'll learn
- defining and implementing traits
- default methods
- `Display` vs `Debug`

## Concepts

Define a trait and implement it on a struct. Most exercises are test-graded.

```rust
fn main() {
    println!("Type examples from this README into playground with `cargo play`.");
```

## Common mistakes
- Implementing a trait for the wrong type — match the impl block to the type.

## Before you start
Run `cargo warm 17` if this level uses external crates (see `level.toml`). Type examples into `playground` with `cargo play`.
