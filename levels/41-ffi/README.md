# Level 41 — FFI

## What you'll learn
- `extern "C"`
- calling C from Rust
- requires a system C compiler

## Concepts

Level bundles `native/add.c`. Install Xcode CLT or `gcc` before this level.

```rust
fn main() {
    println!("Type examples from this README into playground with `cargo play`.");
}
```

## Common mistakes
- Mismatching C and Rust types at the FFI boundary.

## Before you start
Run `cargo warm 41` if this level uses external crates (see `level.toml`). Type examples into `playground` with `cargo play`.
