# Level 46 — Leptos components

## What you'll learn
- SSR with `view!`
- components and props
- graded via HTML output

## Concepts

Drills use server-side rendering only — no browser required.

```rust
fn main() {
    println!("Type examples from this README into playground with `cargo play`.");
}
```

## Common mistakes
- Confusing Leptos components with React — props are Rust values, not JS objects.

## Before you start
Run `cargo warm 46` if this level uses external crates (see `level.toml`). Type examples into `playground` with `cargo play`.
