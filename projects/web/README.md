# Web capstone (Phase 6)

Full-stack Leptos + patterns from `projects/api`. **Gate:** `cargo test -p web`.

## Milestones

1. Leptos SSR app with at least two routes
2. Server functions calling your API (or a mock)
3. `wasm-pack build` for client bundle (document command)
4. Hydration working in browser
5. Deploy front + API; link both URLs here

Drills in levels 44–48 stay SSR-only; this project is where WASM and the browser matter.
