# Web fundamentals (non-graded)

HTML, CSS, and DOM practice before Leptos levels 44–48. Open each folder in a browser (Live Server or `python3 -m http.server`).

## Mini-builds

| Folder | Goal | Checklist |
|--------|------|-----------|
| `01-profile-page/` | Semantic HTML profile | [ ] header/nav/main/footer [ ] one image with alt [ ] accessible headings |
| `02-flexbox-layout/` | Layout without frameworks | [ ] header + sidebar + main [ ] works at narrow width [ ] gap/padding by hand |
| `03-dom-todo/` | DOM events | [ ] add item [ ] mark done [ ] remove item |
| `04-fetch-and-render/` | `fetch` + DOM | [ ] load JSON [ ] render list [ ] show loading/error states |

No Cargo grading — this is checklist-only alongside the Rust browser track.
